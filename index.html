HTML,CSS y JavaScript:

Son tres pilares fundamentales del desarrollo web que trabajan juntos para crrear paginas web dinamicas e interactivas.
HTMLse encarga de la estructura y el contenido,CSSdel diseño y la presentacion,y JavaScriptde la interactividad y la fundionalidad.

Definiciones:

HTML(HyperText
Markup language):

Es el lenguaje de marcado que define la estructura y el contenido de una pagina web.Utiliza etiquetas para delimitar diferente
elementos, como parrafos,encabezados, imagenes, enlaces, etc.

CSS(Cascading Sttyle
Sheets):

Es un lenguaje de estilos que se utiliza para controlar la presentacion de una pagina web.
Permite definir aspectos como los colores,fuentes,tamaños,margenes,etc ,
de los elementos HTML.

JavaScript(Progam.
Languaje):

Es un lenguaje de programacion que permite agregar funcionalidad interactiva a una pagina web.Permite manipular elementos HTML.
responder a eventos del usuario, realizar calculos,etc.
